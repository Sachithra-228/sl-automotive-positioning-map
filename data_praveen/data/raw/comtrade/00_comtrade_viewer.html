1. What is in this folder

One JSON per product (HS code) × flow (import/export) × year. Cell = number of partner rows returned. 0 = file exists but the API returned nothing. A dash = never downloaded.

Vehicle brands → Comtrade

Comtrade has no brand field. Each brand is linked to the HS code that matches its models (EV, hybrid, ICE car, pickup/van, bus) and to the country it is mainly sourced from, then we show what Sri Lanka imported from that country under that code. It is a country-level proxy for the brand, not the brand's own sales.
